### Projects

**Provenance Guard** — Flask API that detects AI-generated text and returns a confidence score instead of a flat yes/no, plus an appeals workflow to challenge a flagged result.
[repo](https://github.com/batyrkhan9/ai201-project4-provenance-guard)

**Unofficial Guide** — RAG system built on real Rate My Professor reviews for Minerva professors. Lets students ask plain-language questions about a professor instead of relying on a single average rating.
[repo](https://github.com/batyrkhan9/ai201-project1-unofficial-guide-starter)

**TakeMeter** — Fine-tuned DistilBERT classifier for categorizing r/worldcup posts. Benchmarked against a zero-shot LLM baseline, which won — documented that result instead of hiding it.
[repo](https://github.com/batyrkhan9/ai201-project3-takemeter)
