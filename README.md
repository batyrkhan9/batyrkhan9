## Projects

**[Provenance Guard](https://github.com/batyrkhan9/ai201-project4-provenance-guard)**
A Flask API that flags AI-generated text and returns a confidence score instead of a plain yes or no. It also has an appeals flow, so a flagged piece of writing can be challenged and re-reviewed. I built it because most detectors hand you a verdict with no way to push back.

**[TakeMeter](https://github.com/batyrkhan9/ai201-project3-takemeter)**
I fine-tuned a DistilBERT classifier to sort r/worldcup posts by type, using live discussion from the 2026 World Cup. I set up a zero-shot LLM as a baseline to compare against, and it ended up beating my fine-tuned model. The repo has the numbers and my notes on why.

**[Unofficial Guide](https://github.com/batyrkhan9/ai201-project1-unofficial-guide-starter)**
A RAG system over real Rate My Professor reviews for Minerva professors. Instead of judging a professor by one average score, you can ask specific questions and get answers from what students actually wrote. Built it for myself first; developing it further now because demand for it is growing across the school.
